# Bài 2: Tái cấu trúc lịch sử commit bằng Interactive Rebase

## Giới thiệu
Bài tập này hướng dẫn cách sử dụng công cụ Git Interactive Rebase để làm sạch lịch sử commit trước khi đẩy lên remote. Các thao tác thực hiện bao gồm squash, reword và drop các commit.

## Các chức năng
- Mô phỏng quá trình tạo các commit nháp.
- Hướng dẫn cấu hình Interactive Rebase để gộp commit, đổi tên thông điệp và xóa commit rác.

## Hướng dẫn chạy chương trình
Chạy script Python để mô phỏng quy trình tự động hóa Git:
```bash
python main.py
```
